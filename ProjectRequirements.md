QuickGPT is a powerful AI assistant application built using the **MERN Stack** and integrated with **Google Gemini API**. It provides fast, intelligent, and human-like conversational responses with a clean and modern user interface.

This project demonstrates full-stack development skills, AI integration, REST APIs, and scalable application architecture.

---

## 🌟 Features

- 🤖 AI-powered chat assistant using **Gemini API**
- ⚡ Real-time AI responses
- 🧠 Context-aware conversations
- 🔐 Secure API key handling using environment variables
- 📱 Fully responsive UI
- 🌐 RESTful API architecture
- 🚀 Scalable MERN stack application

# Frontend Initialization (Initial Stage)

This step initializes the frontend project using **Vite** for faster development
and optimized build performance.

## 📁 Navigate to Frontend Folder

```bash
cd frontend
```

## 🚀 Create Vite + React Project

```bash
npm create vite@latest
```

## 📦 Install Project Dependencies & Start Server

```bash
npm install
npm run dev
```

# Backend Initialization (Initial Stage)

This step initializes the backend project and generates the `package.json` file.

## 📁 Navigate to Backend Folder

```bash
cd backend
```

## 🚀 Initialize Node.js Project

```bash
npm init -y
```
