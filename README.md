# 🤖 QuickGPT – AI Assistant

### Powered by MERN Stack & Google Gemini API

QuickGPT is a **modern, intelligent AI assistant** built using the **MERN Stack** and integrated with **Google’s Gemini API**.  
It delivers fast, accurate, and human-like responses with a clean UI and scalable backend architecture.

This project showcases **full-stack development**, **AI integration**, and **real-world application design**.

---

## 🚀 Features

- 🤖 AI-powered assistant using **Google Gemini API**
- ⚡ Real-time intelligent responses
- 🧠 Context-aware conversations
- 🔐 Secure API key handling with environment variables
- 📱 Fully responsive modern UI
- 🌐 RESTful API architecture
- 🚀 Scalable & production-ready MERN stack app
